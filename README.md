# movie-collection-manager

A lightweight Python application developed for a university project to help users store, organize, and track their personal movie collections.

## Features
- Add & Remove Movies:Keep your personal library up to date.
- Search & Filter: Find movies by title, genre, or release year.
- Ratings & Status: Track watched movies and personal ratings.
